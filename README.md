# 🔢 Machine Learning with scikit-learn

A collection of projects and experiments using **scikit-learn** for machine learning tasks, focusing on regression, classification, and data preprocessing techniques.

---

## 📗 Overview
This repository contains Jupyter notebooks demonstrating various aspects of machine learning using the **scikit-learn** library. The projects cover:

- Data cleaning and preprocessing.
- Handling missing values.
- One-hot encoding categorical data.
- Model evaluation and hyperparameter tuning.
- Regression and classification tasks.
- Comparing the performance of different machine learning models.

---

## 🔄 Datasets Used
1. **Car Sales Dataset** from [Kaggle](https://www.kaggle.com/).
2. **Heart Disease Dataset** from [Kaggle](https://www.kaggle.com/).
3. **Weather Dataset** from [Kaggle](https://www.kaggle.com/).

---

## 🛠️ Tools and Libraries
- **scikit-learn**: For machine learning models and preprocessing.
- **Matplotlib** and **Seaborn**: For data visualization.
- **Pickle**: To save and load trained models.

---

## 🔧 Techniques and Methods
- Data preprocessing: Cleaning data, handling missing values, and one-hot encoding.
- Regression and Classification tasks.
- Ensemble methods.
- Model evaluation and accuracy comparison.
- Hyperparameter tuning to optimize model performance.

---

## 🌟 Projects and Notebooks
1. **basics.ipynb**: Introduction to scikit-learn.
2. **improvingScore.ipynb**: Techniques to improve model accuracy.
3. **regressionEval.ipynb**: Evaluating regression models.
4. **skl_missing.ipynb**: Handling missing values in datasets.
5. **sklearn-workflow-transform.ipynb**: Complete machine learning workflow.
6. **random-forest-model.joblib**: Trained Random Forest model for future predictions.
